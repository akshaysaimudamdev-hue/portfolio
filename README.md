# Akshay Sai: Portfolio

Next.js 14 (App Router), TypeScript, Tailwind CSS, Framer Motion, Lucide.

## Run locally
    npm install
    npm run dev        # http://localhost:3000
    npm run build && npm start   # production check

## Edit content
All text lives in `lib/data.ts`. Set `project.liveUrl` and `project.repoUrl` to show the Live demo and Source code buttons.
Replace `public/Akshay_Sai_Resume.pdf` to update the resume download.

## Deploy on Vercel
Push to GitHub, then import the repo at vercel.com/new. No settings needed. Click Deploy.
